Hi Code Monkey,

I'm Houtamelo, the developer of Spire, a Unity C# package currently undergoing Asset Store vetting.

Spire helps with a common maintenance problem: add a new gameplay state or command, then find every switch that needs another branch. It reports missing cases at compile time and provides IDE quick fixes to generate the branches.

The checks work with generated discriminated unions and with annotated enums and class/interface hierarchies. Union variants carry their own typed payloads, and the Unity integration generates Inspector drawers for authoring them.

I thought the short add-a-variant → missing-case diagnostic → quick-fix workflow could be useful for your Unity programming audience.

The minimum Unity version is 2022.3.62f3. Rider and Visual Studio Community workflows have been verified. Approval and publication are pending. The regular Asset Store price will be US$20.
