## During vetting — description

~~~~text
Save time by catching errors at compile time.

Spire brings exhaustive matching, IDE quick fixes, and discriminated unions to Unity C#.

Adding an enum member, union variant, or concrete type in an enforced class/interface hierarchy can expose the switches that need updating. Spire reports missing cases and provides IDE quick fixes to generate the branches.

Discriminated unions let each variant carry its own typed data. Use them to represent commands, states, and results, with generated factories, Unity serialization and Inspector drawers, and optional JSON converters.
~~~~

## Reply — installation and IDE

~~~~text
The package ships the runtime and compiler extensions together. Keep their DLLs and .meta files together. In Rider, enable Settings → Editor → Inspection Settings → Roslyn Analyzers, then let Unity compile and the IDE refresh its project model. Rider and Visual Studio Community workflows have been verified. Setup:
~~~~
