# Third Party Notices

Spire's four shipped DLLs contain compatibility types generated by PolySharp
1.15.0, by Sergio Pedri. The PolySharp generator DLL is a build dependency and
is not included in this bundle.

Source: https://github.com/Sergio0694/PolySharp
Pinned source commit: 02753db24d9685e54db06739eb63183d86eb5b62
License text: https://github.com/Sergio0694/PolySharp/blob/02753db24d9685e54db06739eb63183d86eb5b62/LICENSE

The shipped compiler-compatibility metadata inventory contains:
AsyncMethodBuilderAttribute, CallerArgumentExpressionAttribute,
CollectionBuilderAttribute, CompilerFeatureRequiredAttribute,
InterpolatedStringHandlerArgumentAttribute, InterpolatedStringHandlerAttribute,
IsExternalInit, IsReadOnlyAttribute, ModuleInitializerAttribute, NullableAttribute,
NullableContextAttribute, OverloadResolutionPriorityAttribute, ParamCollectionAttribute,
RefSafetyRulesAttribute, RequiredMemberAttribute, RequiresLocationAttribute,
SkipLocalsInitAttribute. Some metadata is emitted directly by the C# compiler;
this inventory does not assign every definition to PolySharp.
