# Spire 6.1.2

Spire 6.1.2 fixes compiler exhaustiveness-warning suppression for switch
expressions passed as invocation arguments. All four packages use 6.1.2.

Calls such as `callback?.Invoke(route switch { ... })` now suppress CS8509 or
CS8524 when Spire proves the switch exhaustive. Roslyn's syntax lookup previously
selected the enclosing argument when it shared the switch expression's span.

Missing members, guarded arms, missing null cases, and indeterminate patterns
retain their compiler warnings. Regression tests also verify that sibling and
nested switches suppress only their own diagnostics.

Validation includes real Roslyn compilation and suppression tests, the portable
analyzer suite, generator exhaustiveness tests, and the affected project compiled
with Unity 6000.5.6f1's bundled compiler.
