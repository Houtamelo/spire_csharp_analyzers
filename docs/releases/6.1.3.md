# Spire 6.1.3

Spire 6.1.3 fixes generated nullable warnings when variants share reference
storage. All four packages use 6.1.3.

Storage annotations now merge parameters from authored record-struct variants
as well as factory methods. Active payload reads retain their declared
nullability, removing CS8604 warnings from generated equality and accessors
without changing public payload annotations or runtime equality behavior.

Regression coverage includes both declaration orders, typed/auto/shared storage,
mixed factory and record variants, nested generic annotations, and runtime null
equality. Validation includes Unity's BCL references and the affected project
compiled with Unity 6000.5.6f1's bundled compiler.
