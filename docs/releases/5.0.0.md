# Spire 5.0.0

2026-11-08

Spire 5.0.0 brings the union payload redesign, Unity integration, and accumulated
analyzer, generator, and code-fix improvements to ordinary .NET projects. It is a
breaking release relative to NuGet 4.7.1. All three packages use version 5.0.0:
`Houtamelo.Spire`, `Houtamelo.Spire.Analyzers`, and `Houtamelo.Spire.CodeFixes`.

```sh
dotnet add package Houtamelo.Spire --version 5.0.0
```

The bundle includes the runtime API, analyzers, generator, and code fixes. Keep
explicit standalone package references on the same version if you use them.

## Changes

- Struct unions expose typed variant payloads with readonly getters and typed
  deconstruction. Public variants also support implicit conversions from their
  payload structs to the union. Concrete unmanaged storage overlaps without unsafe code;
  managed storage uses the new `ReferenceStorage` policy.
- SPIRE013/014 follow short-circuit `&&`/`||`, positive and negative comparisons,
  nested conditions, saved predicates, loops, and early exits. Receiver identity,
  aliases, callbacks, and mutation effects determine whether a guard remains valid.
- Exhaustiveness and IDE quick fixes understand generated variant predicates,
  nested payload patterns, precise integral boundaries, and wide enum values.
  Inliner generation preserves constraints and semantic identifiers.
- Unity serialization and Inspector drawers require Unity compilation symbols
  and APIs. `[System.Serializable]` alone does not activate Unity generation in
  an ordinary .NET consumer. Invalid Unity discriminators restore the first
  declared variant.
- The maintained CoreCLR/NuGet suite installs actual packed packages into
  ordinary .NET consumers. Separate Unity suites retain their metadata and
  native runtime coverage.

## Migrate from 4.x

| Previous API | 5.0 replacement |
|---|---|
| `Layout`, the `layout:` constructor argument, and `Spire_DU_DefaultLayout` | Remove them. Use `ReferenceStorage` for managed slot policy; unmanaged storage is automatic. |
| `GenerateDeconstruct`, the `generateDeconstruct:` argument, and `Spire_DU_DefaultGenerateDeconstruct` | Remove them. Deconstruct a variant payload. |
| Flat union fields such as `command.x` | Read `command.move.x` after a matching guard, or capture the payload in a pattern. |
| Union-level positional patterns and `Deconstruct` | Match a generated predicate and deconstruct its payload. |
| A union nested inside a generic containing type | Move the union outside the generic ancestor; SPIRE_DU018 diagnoses this unsupported placement. The union itself may remain generic. |

Replace declarations such as:

```csharp
[DiscriminatedUnion(layout: Layout.Additive,
    generateDeconstruct: GenerateDeconstruct.Yes)]
```

with `[DiscriminatedUnion]`, or select a managed storage policy explicitly:

```csharp
using Houtamelo.Spire;

[DiscriminatedUnion(ReferenceStorage = ReferenceStorage.Typed)]
public partial struct Command
{
    [Variant] public static partial Command Move(int x, int y);
    [Variant] public static partial Command Stop();
}
```

Replace flat property patterns such as
`{ kind: Command.Kind.Move, x: var x, y: var y }` with payload patterns:

```csharp
string Describe(Command command) => command switch
{
    { IsMove: true, move: var (x, y) } => $"Move to {x}, {y}",
    { IsStop: true } => "Stop",
};

bool MovesRight(Command command) => command.IsMove && command.move.x > 0;
```

Payload accessors return copies with getter-only properties. Construct replacements
through a factory or a new payload rather than mutating a captured payload:

```csharp
Command command = new CommandTypes.Variants.Move(10, 20);
```

The global replacement setting is
`<Spire_DU_DefaultReferenceStorage>Auto</Spire_DU_DefaultReferenceStorage>`.
`Typed` reuses compatible typed slots without boxing; `Shared` reuses object
slots and may box managed structs. `Auto` chooses Shared only when its reused
slot count is at most half the Typed count. These settings are not one-to-one
replacements for the old layout strategies. JSON constructor options and
`Spire_DU_DefaultJson` / `Spire_DU_DefaultJsonDiscriminator` remain available.
The logical JSON wire format retains its discriminator and variant fields;
generated in-memory storage and raw struct layout have changed.

A guard must apply to the same unchanged receiver. For a property or indexer,
capture a local snapshot before checking its variant. Calls or aliases that can
mutate a guarded value require a fresh check. Some previously accepted unsafe
programs now produce diagnostics. See [SPIRE014](../rules/SPIRE014.md).

See the [union guide](../discriminated-unions.md) for payload naming, generic
types, record unions, JSON, and storage details. Ordinary .NET projects need no
Unity installation or assembly references. The Unity Asset Store submission
remains a separate 4.7.6 submission; this NuGet release does not resubmit it.

## Validation

The implementation passed 2,716 CoreCLR/NuGet tests, 95 Unity metadata tests,
and 2,996 actual Unity 6000.5.6f1 Editor Mono checks on Linux, with no failures or
skips in those lanes. Minimum Roslyn 4.3.1 probes and guard-flow scaling and
cancellation checks also passed. The generated correctness corpus executes
512 consumers over 12 bounded inputs. These are bounded integration results;
host lanes overlap and their counts must not be added as independent cases.
